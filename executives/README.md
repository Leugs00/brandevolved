# executives/

Cross-functional workspace for COO, CFO, and CMO. Provides visibility and coordination across all three business tiers.

## Subdirectories

| Path          | Contents                                       |
|---------------|------------------------------------------------|
| `strategy/`   | Annual goals, OKRs, long-range planning        |
| `finance/`    | Budgets, forecasts, actuals by tier            |
| `marketing/`  | Brand guidelines, campaign coordination        |
| `reporting/`  | KPI tracking, dashboards, cross-tier metrics   |

## Access Note

Files in `finance/` are confidential. Do not share outside exec team without approval.
