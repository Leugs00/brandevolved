# BrandEvolved

Multi-tier business platform combining education, agency services, and SaaS.

## Structure

| Directory           | Purpose                                        |
|---------------------|------------------------------------------------|
| `executives/`       | Shared exec workspace — COO, CFO, CMO          |
| `edu/`              | DIY/Education tier — courses, content          |
| `agency/`           | Agency services — client work, projects        |
| `brandtrue-saas/`   | BrandTrue SaaS product — app, features, docs   |

## Quick Start

```bash
cp .env.example .env
# Fill in your values
```
