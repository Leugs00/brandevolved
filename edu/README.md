# edu/ — DIY / Education Tier

Self-serve education products: courses, content, and downloadable resources.

## Subdirectories

| Path          | Contents                                              |
|---------------|-------------------------------------------------------|
| `courses/`    | Course outlines, modules, scripts, recordings index   |
| `content/`    | Blog posts (`blog/`), social copy (`social/`)         |
| `resources/`  | Downloads, templates, lead magnets                    |

## Naming Conventions

- Course folders: `courses/<slug>/` (e.g. `courses/brand-foundations/`)
- Blog drafts: `content/blog/YYYY-MM-DD-title.md`
